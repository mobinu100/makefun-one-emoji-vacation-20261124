Entry for the [make.fun](https://make.fun/c/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) competition "One Emoji, One Dream Vacation".

The entry is exactly one emoji: ⛵ — a sailboat on open water. The dream is the journey itself: sailing the Greek isles at golden hour, no itinerary, just wind and sea.

Why a sailboat and not a beach: a beach is any holiday, but a sailboat is one particular dream — wind, open water, and somewhere far away that you can only reach by going.

Run it with `node main.ts`. It writes the single emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` by default).
